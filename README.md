# VextCalc-My-Rust-Calculator

## What is VextCalc?🧮

VextCalc is a calculator that solves simple operations (addition, subtraction, multiplication, and division). It can solve first-degree equations and second-degree equations using the quadratic formula. The calculations performed by the computer are stored, meaning you can review the same equation you did previously.
